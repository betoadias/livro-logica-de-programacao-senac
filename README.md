# Lógica de Programação (Senac)

Repositório de estudos do livro **Lógica de Programação (Senac)** dentro da minha jornada em Engenharia de Software (`betoadias`).

---

## Como Este Repositório Está Organizado
- `anotacoes/` — resumos e conceitos anotados durante a leitura.
- `exercicios/` — códigos e exercícios resolvidos por seção ou capítulo.
- `projeto-final/` — entrega prática ou conjunto final ao concluir o livro.
- `docs/` — observações, casos de borda e decisões de organização.

---

## Padrão de Commits

Formato:

< tipo > (< parte >): o que foi feito

Onde `<parte>` pode ser `intro`, `cap-01`, `cap-02`, etc.

Tipos:
- `anotacoes:` anotações do conteúdo do capítulo/`
- `exercicios:` exercícios resolvidos
- `ajustes:` melhoria no conteúdo já existente
- `complemento:` adicionando um complemento no conteúdo já existente

Exemplo:
- `anotacoes(introducao): adiciona anotacoes sobre hardware, software e termos basicos`

---

## Sumário de Estudo
- **Setup:** estrutura inicial do repositório e padrão de commits
- **Introdução:** hardware e software; familiarização com termos de programação *(concluído)*
- **Capítulo 1:** lógica de programação e suas representações *(em andamento)*
